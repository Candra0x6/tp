# DEMO VIDEO RECORDING GUIDE (40 SECONDS)

Follow this shot-by-shot guide to record the official 40-second submission video for **TRUST FALL**.

---

## Recording Setup

- **Resolution**: 1920 × 1080 (or 4K), 60 FPS.
- **Scale**: Record browser windows at 2× zoom so the 8px Departure Mono font and pixel art remain crisp.
- **Layout**: Two browser windows side-by-side (Window 1: Player 1 / Host, Window 2: Player 2 / Joiner) or side-by-side with a terminal.
- **Audio**: No voiceover required. Add background chiptune track or keep muted; clear onscreen captions carry the story.
